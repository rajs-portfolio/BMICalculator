# ⚖️ BMI Calculator

A simple **BMI (Body Mass Index) Calculator** built with Python.
The program takes the user's **weight and height**, calculates their BMI, and displays the corresponding BMI category.

## ✨ Features

* ⚖️ Calculate BMI using weight and height
* 📊 Display BMI up to 2 decimal places
* 🏷️ Categorize BMI as:

  * Underweight
  * Normal weight
  * Overweight
  * Obese
* 🖥️ Simple command-line interface
* 🐍 Beginner-friendly Python project

## 🧮 BMI Formula

The BMI is calculated using:

```text
BMI = Weight (kg) / Height² (m)
```

## 📋 BMI Categories

| BMI Range   | Category      |
| ----------- | ------------- |
| Below 18.5  | Underweight   |
| 18.5 – 24.9 | Normal weight |
| 25 – 29.9   | Overweight    |
| 30 or above | Obese         |
